# wake_prefix

AstrBot 群聊发言节奏插件（`astrbot_plugin_group_pace`）。在请求聊天模型之前，按点名、接话窗口、随机概率和冷却决定是否回复，减少群内逐条回复。

## 安装

在 AstrBot 插件管理中通过仓库地址安装：

```text
https://github.com/wy404email-a11y/wake_prefix
```

私聊不受限制。支持 aiocqhttp；当前实现面向 AstrBot 本地聊天模型流程。

## 1.0.0 行为

- 被 @、引用机器人、提到配置中的昵称时放行。
- 默认接话窗口为 45 秒；窗口内放行会续期，窗口按会话共享。
- 窗口外以 20% 概率插话，两次随机插话至少间隔 180 秒。
- 使用 `/pace` 查看设置和放行、静默统计。
- 所有参数可在插件配置中调整，仓库不包含部署环境的个人配置。

## 唤醒与概率

本插件只过滤已经进入聊天模型请求流程的消息，本身不负责唤醒。希望普通群消息也参与判断时，可在框架配置中使用包含空串的唤醒前缀（例如 `["/", ""]`），并配合群白名单限制作用范围。若使用框架自带的概率主动回复，两处概率会叠加。

静默可以阻止后续聊天回复请求，但框架前置的图片描述等功能仍可能调用模型。

## 已知限制

1.0.0 保留原插件逻辑：接话窗口由整个会话共享且可持续续期；时间和统计记录的是请求放行，不是实际成功发送；框架剥离唤醒前缀后，斜杠提问可能被误判为普通聊天。这些行为将在后续版本改进。
