# wake_prefix

AstrBot 群聊发言节奏插件（`astrbot_plugin_group_pace`）。在本地聊天模型请求前，按点名、成员接话窗口、随机概率与冷却决定是否回复。私聊不受限制。

## 安装与升级

在 AstrBot 插件管理中，通过以下仓库地址安装：

```text
https://github.com/wy404email-a11y/wake_prefix
```

仓库根目录就是插件目录，无第三方 Python 依赖。保留原插件名称，升级会继续使用原有概率、窗口、冷却和称呼配置；新增配置缺失时使用默认值。

## 1.1.0 行为

1. 被 @、引用机器人、使用非空唤醒前缀或符合称呼规则时放行，不受随机冷却限制。
2. 成功回复后，为发送消息的成员开启接话窗口。其他成员需要单独点名或参与随机插话。
3. 默认接话窗口 45 秒，每段对话最多自动接 3 轮，最长 180 秒。有效接话成功后可续期，但不会延长整段对话的总时长。再次明确点名会重开窗口。
4. 窗口外默认以 20% 概率插话，成功发送随机插话后，本会话冷却 180 秒。随机请求处理中先预留名额，避免多人同时命中。
5. 请求失败或发送失败不记作成功回复，也不启动实际插话冷却。尚未开始发送的自动回复预留过期后，不再发送其迟到结果；明确点名的请求仍允许晚回复。已经开始发送的内容可完成后续分段。

“成功发送”表示平台发送接口正常返回，不代表用户已读。非流式逐段记录成功发送，整次事件只计一条成功回复；流式需要非空正文、模型正常完成且发送接口正常返回才计数。仅错误提示、推理或工具状态不打开窗口。

## 配置

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `enabled` | `true` | 是否过滤群聊请求 |
| `reply_probability` | `0.2` | 窗口外随机插话概率 |
| `followup_window_seconds` | `45` | 同一成员的接话窗口秒数，0 禁用 |
| `max_followup_replies` | `3` | 首次回复后最多自动接话轮数，0 禁用 |
| `max_conversation_seconds` | `180` | 整段自动接话的总时长，0 禁用 |
| `cooldown_seconds` | `180` | 成功随机插话后的冷却秒数 |
| `pending_timeout_seconds` | `300` | 尚未开始发送的请求预留秒数 |
| `address_words` | 大肥鱼、小鲸鱼、鲸鱼 | 机器人称呼，可自行更换 |
| `address_match_mode` | `prefix` | `prefix` 为句首称呼，`contains` 为任意位置包含 |

默认称呼需后接空白或标点，例如“鲸鱼，帮我看看”。“今天看了鲸鱼纪录片”不会触发。设置 `contains` 可以恢复旧版宽松匹配。

## 唤醒与概率

本插件过滤已经进入聊天模型流程的消息，本身不负责唤醒。要让普通群消息参与判断，可在框架使用包含空串的唤醒前缀，例如 `["/", ""]`，并用群白名单限定范围。

框架的“概率主动回复”与插件概率会叠加：适用会话先经过框架 10% 筛选，再经过插件 8% 筛选时，窗口外且冷却结束后的综合概率约为 0.8%。希望统一由插件调节时，应在 AstrBot 设置中配置空串唤醒，并关闭对应会话的框架概率主动回复。插件不会自动改动框架配置。

`/pace` 显示本会话设置、你的窗口余量、剩余轮数、冷却、请求放行原因、静默及成功回复事件数，并提示空串唤醒与框架概率设置。

## 协作与边界

- 目标平台为 aiocqhttp，使用 AstrBot 本地 agent runner。第三方 Dify、Coze、DashScope 等流程不经过本插件使用的等待钩子，暂不支持。
- 基于 AstrBot 4.29.4 运行源码核对接口，独立测试使用 API 替身；没有执行真实 QQ 群发言测试。
- 在会话锁和 reply_merge 等待窗口前判断，priority=100。合并插件在更早阶段接收的后续消息不会再次经过本闸门，统计也不包含它们；一条合并回复计一个成功事件。
- 框架前置图片描述等功能可能在闸门前调用模型，静默无法免除这部分成本。
- 若框架取消请求、空结果直接结束或其他插件提前截断，没有通用结束回调时，预留依赖 `pending_timeout_seconds` 释放。该设置应大于常见模型请求耗时；它不会取消底层请求。已经进入发送接口的请求保留预留，直至返回或异常。
- 对话和统计只保存在内存，重启清空；闲置 24 小时的会话会在后续访问时回收。默认按群共享随机冷却；若框架开启成员独立会话，则冷却和统计也随会话隔离。
